# Pet Needs — website

De gepubliceerde website van dierenspeciaalzaak **Pet Needs**, Choorstraat 49, Delft.

- **Nederlands:** https://chenxi981211-ui.github.io/Pet-need/
- **English:** https://chenxi981211-ui.github.io/Pet-need/en/

Deze repo bevat alleen het **gegenereerde resultaat** (HTML, CSS, JS en beeld) en
wordt door GitHub Pages vanaf branch `main` gepubliceerd.

De bron — de generator (`scripts/`), alle teksten (`scripts/i18n.py`), de data
(`data/site.json`) en de originele foto's — staat in de privérepo
`chenxi981211-ui/petneeds-source`. Wijzigingen maak je daar, waarna
`scripts/deploy.sh` het resultaat hierheen publiceert.
